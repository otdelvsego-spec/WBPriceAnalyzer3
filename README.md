# WB Price Analyzer

Локальное Windows-приложение для анализа еженедельных детализированных
финансовых отчетов Wildberries. Интерфейс и рабочий процесс основаны на
OZ Price Analyzer v0.5.2, а расчетное ядро адаптировано к 84 полям отчета WB.

## Возможности

- объединение основного отчета и отчета WB «по выкупам» за одну ISO-неделю;
- распределение всех денежных операций с артикулом на товар, без артикула —
  в отдельную «Разбивку»;
- справочник себестоимости и категорий, заполняемый в приложении или из XLSX;
- история недельных расчетов, контроль качества, сравнение и динамика;
- просмотр любых XLSX без запуска Excel;
- сценарий доходности при изменении плановой розничной цены;
- изменяемая высота таблиц на вкладках «Обзор», «Сценарий цены» и
  «Настройки» с сохранением доступности верхних кнопок и фильтров;
- явная пометка «Нет продаж» вместо вводящей в заблуждение доходности 0%;
- постоянное предупреждение о строках справочника без полной себестоимости;
- экспорт результата в XLSX с листами «Итог», «Разбивка» и
  «Справочник операций».

## Ключевой принцип расчета

Столбец «К перечислению Продавцу за реализованный Товар» уже учитывает
комиссию Wildberries и платежные услуги. Поэтому комиссия и эквайринг
показываются справочно и не вычитаются второй раз. Из перечисления вычитаются
логистика, штрафы, хранение, приемка, удержания и другие отдельные компоненты;
компенсации программы лояльности добавляются с учетом типа документа.

## Запуск из исходного кода

```bash
python -m pip install -r requirements.txt
python main.py
```

Для сборки Windows используйте `build_windows.bat` или workflow
`Windows application` в GitHub Actions.
