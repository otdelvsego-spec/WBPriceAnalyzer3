# WB Price Analyzer

Локальное Windows-приложение для анализа еженедельных детализированных
финансовых отчетов Wildberries. Интерфейс и рабочий процесс синхронизированы с
OZ Price Analyzer v0.5.21, а расчетное ядро адаптировано к 85 полям отчета WB.

## Возможности

- отдельный расчет основных продаж и выкупов WB с объединением в один
  финансовый результат за ISO-неделю;
- импорт уведомления о выкупе XLSX и автоматическая связь с детализированным
  отчетом по номеру;
- распределение всех денежных операций с артикулом на товар, без артикула —
  в отдельную «Разбивку»;
- справочник себестоимости и категорий, заполняемый в приложении или из XLSX;
- история недельных расчетов, контроль качества, сравнение и динамика;
- просмотр любых XLSX без запуска Excel;
- сценарий доходности при изменении плановой розничной цены;
- четыре процентных показателя в «Обзоре», «Динамике» и экспортируемом XLSX:
  средняя комиссия, логистика, баллы и чистая прибыль от выручки;
- в карточках «Обзора» сумма комиссии, логистики и баллов в рублях показана
  рядом с соответствующим процентом от выручки;
- доходность в общем графике «Динамики» и фильтр периода по текущему году
  либо выбранным годам истории;
- независимая настройка видимости и порядка столбцов таблиц «Обзор» и
  «Сценарий цены»;
- изменяемая высота таблиц на вкладках «Обзор», «Сценарий цены» и
  «Настройки» с сохранением доступности верхних кнопок и фильтров;
- явная пометка «Нет продаж» вместо вводящей в заблуждение доходности 0%;
- постоянное предупреждение о строках справочника без полной себестоимости;
- экспорт результата в XLSX с листами «Итог», «Разбивка» и
  «Справочник операций».
- единственный экземпляр приложения: повторный запуск восстанавливает уже
  открытое окно вместо создания второго.
- новый столбец WB «Коэффициент логистики» распознается как справочный:
  денежная логистика уже содержит его влияние и не пересчитывается повторно;
- строки-корректировки с датами соседней недели учитываются в текущем отчете
  и записываются в «Контроль качества» без ложного сообщения о несовпадении периодов.

## Исходные файлы одной недели

- основной еженедельный детализированный отчет WB — обязателен;
- детализированный отчет «по выкупам» — если WB его сформировал;
- уведомление о выкупе XLSX — обязательно для каждого отчета «по выкупам».

## Ключевой принцип расчета

Столбец «К перечислению Продавцу за реализованный Товар» уже учитывает
комиссию Wildberries и платежные услуги. Поэтому комиссия и эквайринг
показываются справочно и не вычитаются второй раз. Из перечисления вычитаются
логистика, штрафы, хранение, приемка, удержания и другие отдельные компоненты;
компенсации программы лояльности добавляются с учетом типа документа.

Основная выручка определяется по столбцу `Пр` с учетом возвратов. Для выкупа
выручка, количество и налоговая база берутся из уведомления XLSX. Возврат
конечного покупателя не отменяет состоявшийся выкуп товара ООО «РВБ».
Связанные комиссия и логистика, уже учтенные WB в цене выкупа, показываются
аналитически, но не уменьшают финансовый результат повторно.

Процентные показатели используют объединенную выручку MAIN + BUYOUT как знаменатель. Комиссия,
логистика и расходы программы лояльности показываются положительной долей
расхода. «Чистая прибыль, % от выручки» учитывает нераспределенные доходы и
расходы всего отчета. Доходность рассчитывается по чистой прибыли товаров и
себестоимости проданных товаров без распределения общих расходов между
артикулами. Кнопка «Настроить столбцы…» на вкладках «Обзор» и «Сценарий цены»
позволяет скрывать столбцы и менять их порядок; настройки сохраняются отдельно.

## Запуск из исходного кода

```bash
python -m pip install -r requirements.txt
python main.py
```

Для сборки Windows используйте `build_windows.bat` или workflow
`Windows application` в GitHub Actions.
