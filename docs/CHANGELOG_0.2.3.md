# WB Price Analyzer 0.2.3

- Добавлена поддержка нового необязательного столбца WB «Коэффициент логистики».
- Коэффициент сохраняется при разборе исходного файла как справочное значение, но не применяется повторно: сумма в столбце «Услуги по доставке товара покупателю» уже рассчитана WB с учетом коэффициента.
- Просмотр исходного XLSX расширен с 84 до 85 столбцов.
- Строки с датами соседней недели распознаются как корректировки, учитываются в текущем расчете и записываются в «Контроль качества» без блокирующего окна.
- Окно подтверждения теперь появляется только при реальном несовпадении недель или при неизвестном приложению изменении формата WB.
- Для неизвестных столбцов заголовок и кнопка окна больше не сообщают ошибочно о несовпадающем периоде.
