# WB Price Analyzer: модель данных и расчетов

## Исходные файлы

Приложение принимает еженедельный детализированный отчет Wildberries в XLSX.
Основной отчет и отчет «по выкупам» за одну ISO-неделю объединяются в один
расчет. Отчеты разных недель сохраняются отдельными строками истории.

Период определяется по преобладающей ISO-неделе столбца «Дата продажи».
Строки с датой другой недели считаются корректировками, учитываются в расчете и
порождают предупреждение контроля качества.

## Поля отчета WB

| Поле WB | Использование |
|---|---|
| Тип документа | Продажа — положительный знак, Возврат — отрицательный |
| Обоснование для оплаты | Группировка на листе «Разбивка» и в справочнике операций |
| Артикул поставщика | Распределение на товар; пустой артикул — нераспределенная операция |
| Кол-во | Продажи/возвраты; значение 2 у возмещения перевозчика не является продажей |
| Цена розничная | Выручка и налоговая база по умолчанию |
| Вайлдберриз реализовал Товар | Фактическая цена для покупателя, аналитика |
| К перечислению Продавцу | Доход продавца после комиссии и платежных услуг |
| Вознаграждение WB и НДС | Комиссия для анализа, повторно не вычитается |
| Компенсация платежных услуг | Эквайринг для анализа, повторно не вычитается |
| Возмещение ПВЗ | Компонент комиссии для анализа, повторно не вычитается |
| Услуги по доставке | Расход на логистику |
| Общая сумма штрафов | Расход; отрицательное значение становится возвратом |
| Хранение | Расход; обычно без артикула и поэтому попадает в «Разбивку» |
| Операции на приемке | Расход |
| Корректировка вознаграждения | Положительное значение — удержание, отрицательное — выплата |
| Удержания | Положительное значение — удержание, отрицательное — выплата |
| Компенсация скидки лояльности | Доход при продаже, обратный знак при возврате |
| Стоимость участия и баллы | Расход при продаже, обратный знак при возврате |
| Разовое изменение срока перечисления | Положительное значение — расход |
| Возмещение перевозчика | Нейтральная контрольная величина, не влияет на доход |

## Формулы

Для строки детализированного отчета:

```text
Знак документа = -1 для возврата, иначе +1

Результат строки =
  Знак × К перечислению продавцу
  - Логистика
  - Штрафы
  - Хранение
  - Приемка
  - Корректировка вознаграждения
  - Удержания
  + Знак × Компенсация лояльности
  - Знак × Стоимость участия
  - Знак × Баллы
  - Плата за ускоренное перечисление
```

Комиссия WB, эквайринг и ПВЗ не вычитаются еще раз: они уже учтены в столбце
«К перечислению Продавцу».

```text
Финрезультат товара = сумма результатов строк с артикулом
Нераспределенные = сумма результатов строк без артикула
Налог = Цена розничная × ставка налога
Чистая прибыль товара = Финрезультат товара - Себестоимость проданного - Налог
Чистая прибыль отчета = сумма чистой прибыли товаров + Нераспределенные
```

Если продаж нет, база для расчета доходности отсутствует. В интерфейсе и
экспорте такая строка помечается «Нет продаж», а не 0%. Если продажи есть, но
себестоимость не заполнена, показывается «Нет себестоимости».

## Сценарий цены

Количество продаж остается текущим. Из выбранного периода вычисляется доля
перечисления продавцу:

```text
Доля перечисления = К перечислению / Цена розничная
Постоянные расходы WB = К перечислению - Финрезультат WB
Плановое перечисление = Плановая цена × Продажи × Доля перечисления
Плановая чистая прибыль =
  Плановое перечисление
  - Постоянные расходы WB
  - Налог с плановой цены
  - Себестоимость проданного
```

Модель сохраняет текущий объем и абсолютные логистические/прочие расходы. Для
резкого изменения объема следует создавать отдельный сценарий вручную, потому
что логистика и хранение могут измениться нелинейно.

## Контроли качества

- повторный выбор одного файла блокируется по SHA-256;
- повторный период предлагает обновить отчет или отменить импорт;
- неизвестные артикулы требуют создать товар или явно пропустить его;
- операции по архивному товару продолжают учитываться;
- расходы с артикулом учитываются даже при нулевых продажах;
- контроль распределения требует равенства суммы исходных строк сумме товаров,
  нераспределенных операций и явно пропущенных артикулов;
- отсутствие отчета WB «по выкупам» показывается предупреждением.
- строки XLSX-справочника без полной себестоимости пропускаются только после
  подтверждения и остаются видимым предупреждением на вкладке «Настройки»;
- высоту таблиц на вкладках «Обзор», «Сценарий цены» и «Настройки» можно менять
  горизонтальным разделителем; верхние элементы управления защищены
  минимальной высотой.
