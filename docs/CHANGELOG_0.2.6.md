# WB Price Analyzer 0.2.6

- Исправлена доходность строки «Итого с нераспределенными» в экспортируемом
  XLSX: показатель пересчитывается по чистой прибыли с нераспределенными
  доходами и расходами, а не повторяет итог только по товарам.
- «Чистая прибыль» и «Доходность» на вкладке «Динамика», в истории отчетов и
  сравнении периодов теперь используют единый финансовый результат всего
  отчета с учетом нераспределенных сумм.
- Доходность отдельных товаров, категорий и сценария цены по-прежнему не
  распределяет общие расходы между артикулами.
