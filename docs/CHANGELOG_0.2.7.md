# WB Price Analyzer 0.2.7

- Исправлен двойной учет компенсации скидки по программе лояльности.
- Компенсация остается отдельным аналитическим показателем, но больше не
  прибавляется повторно к финансовому результату MAIN или BUYOUT.
- Формула комиссии не изменена: приложение по-прежнему показывает комиссию
  нетто по данным детализированного отчета WB.
