# WB Price Analyzer 0.2.5

- Добавлена отдельная расчетная модель основных продаж (`MAIN`) и выкупов
  ООО «РВБ» (`BUYOUT`) с единым итоговым финансовым результатом.
- Основная выручка и налоговая база рассчитываются по столбцу `Пр`:
  продажи минус возвраты.
- Выручка, количество и налоговая база выкупа берутся из соответствующего
  уведомления о выкупе XLSX, строка «Итого» и товарные строки.
- Уведомление автоматически связывается с детализированным отчетом по номеру;
  неполный или несогласованный комплект файлов блокирует окончательный импорт.
- Возврат конечного покупателя не уменьшает количество уже состоявшегося
  выкупа ООО «РВБ».
- Комиссия и связанная логистика, уже заложенные в цену уведомления, не
  вычитаются из результата выкупа повторно; отдельные расходы сохраняются.
- На «Обзоре» и в XLSX доступны общие показатели, а также отдельные продажи и
  выручка MAIN/BUYOUT. Канальные столбцы по умолчанию скрыты и включаются через
  существующую настройку столбцов.
- Старые сохраненные расчеты помечаются статусом «Требует пересчета»; для
  корректного обновления их нужно повторно импортировать вместе с уведомлениями.
